## VIDEO-only sequence evidence in B0/EventGraph

`GroundedEventGraph` now accepts optional `AVFeatureBatch` records. It carries exact frame PTS, token shapes, encoder revision, preprocessing version, and frame evidence references into overlapping graph nodes. The source PTS offset is explicit metadata. The feature status is labeled `encoder_features_only`; it does not create an entity, action, or object claim. Qwen still receives accepted timeline claims only, because these untrained features do not have a validated interpretation path.

Four independently encoded IMAGE sequences at excerpt PTS `0, 2000, 4000, 6000ms` map to original-film PTS `120000, 122000, 124000, 126000ms`. The resulting graph contains 12 event nodes, one visual sequence, and three narration requests. The run confirms the data path and PTS alignment; it does not confirm the action recognizer.

An agent inspection of the frames suggests the candidate `man_1 rises from bed_1 to standing` over 02:00:00–02:00:08. This is not an independent human label. The production matcher still emitted no entity-action-object event; the initial 24/24 visual L1 matches remained uncertain, and the action probe's best top/runner-up margin was only 0.011.
