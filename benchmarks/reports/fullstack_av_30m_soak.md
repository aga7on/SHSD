## Scope

Short `--cycles 1` runs are concurrency smoke measurements, not endurance-soak completion. Use `--duration-minutes 1`, `5`, `10`, or `30` to keep replaying the fixture at the selected concurrency for the requested wall time. Each cycle is a fresh CLI process and incurs process/model startup cost; embedding caches persist within a run directory. Token throughput is the measured llama.cpp generation rate; it is unavailable when L3 is off or timing output is absent.

## Cache qualification

This is a warm-cache repeated-file soak, not a unique-media inference throughput result. In the first 2x stream timeline, all nine embedding records had `cache_hit=true` and none missed. The run remains useful for sustained process startup, prefetch/ring behavior, memory, disk queue, and downstream scheduling under repeated identical input. Use the isolated-cache results in [`fullstack_embedding_worker_cold_cache.md`](fullstack_embedding_worker_cold_cache.md) for a cold-media comparison; that one-cycle smoke is not an endurance soak.
